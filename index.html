¿Qué es HTML5?

HTML5 sustituye no sólo a HTML4, sino también a XHTML1 y DOM Nivel 2. Esta versión permite una mayor interacción entre las páginas web y el contenido multimedia (video, audio, entre otros), así como una mayor facilidad a la hora de codificar el diseño básico de un sitio.

Etiquetas semánticas

HTML5 introdujo nuevas etiquetas semánticas para estructurar los documentos, evitando el uso excesivo de <div> para identificar cada bloque de la página:

  • <header>: encabezado del documento o de una sección.
  • <nav>: crea un menú de navegación.
  • <section>: agrupa contenido relacionado.
  • <article>: define un artículo, comentario o publicación independiente.
  • <aside>: contenido relacionado indirectamente, como una barra lateral.
  • <footer>: pie de página o de sección.

Dato extra

Las etiquetas header y footer ahorran tener que insertar IDs para cada bloque, como se hacía antes con <div id="header">. Además, pueden usarse dentro de cada sección, no solo de forma general.

Elementos multimedia

<video>

Permite reproducir video sin necesidad de plugins externos.

<audio>

Permite reproducir audio directamente en el navegador.

<canvas>

El elemento canvas permite dibujar gráficos por vectores usando JavaScript, funcionando como un "lienzo" dentro del documento.
